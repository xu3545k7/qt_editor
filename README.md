# NOS Chart Maker（qt_editor）

給 Nostalgia 類型鋼琴音樂遊戲用的譜面編輯器。可以把 MIDI 轉成遊戲譜面、
用鋼琴捲軸的方式編輯、聽內建鋼琴音源試聽，再匯出成遊戲吃得下的 XML / JSON。

## 這是什麼

一份 MIDI 進來，一份可以直接放進遊戲的譜面出去。中間你可以：

- 把 88 鍵的鋼琴音高**排成遊戲的 28 條鍵道**（自動排譜，兩種風格可選）
- 用**音高模式**像鋼琴捲軸一樣看譜、改音高
- 編輯**力度**（velocity）與**延音踏板**，並用內建音源試聽
- 調整 **BPM、拍號、小節**，包括多小節批次修改
- 匯出成 **XML / JSON 譜面**、**MIDI**，或連同音訊打包成完整曲目

譜面格式支援官方 XML（含 `sub_note` 的一鍵多音、trill、slide）與本專案的 JSON。

## 安裝與執行

### 直接用打包好的執行檔

`dist/NostalgiaChartEditor.exe` 打開就能用，不需要裝 Python。
第一次啟動要解壓縮，可能要等 30～60 秒。

### 從原始碼跑

需要 **Python 3.11**（開發環境是 3.11.9）。

```bash
pip install PyQt5 mido
pip install simpleaudio          # 選用：沒有的話會退回 winsound
python -m qt_editor.app
```

也可以直接帶檔案路徑開啟：

```bash
python -m qt_editor.app path/to/chart.xml
```

| 套件 | 必要性 | 用途 |
|---|---|---|
| `PyQt5` | **必要** | 整個介面 |
| `mido` | **必要** | 讀寫 MIDI |
| `simpleaudio` | 建議 | 音訊播放後端；沒有的話用 winsound，功能較少 |
| FluidSynth | 選用 | 內建鋼琴音源（試聽、匯出鋼琴音軌）。DLL 放在 `vendor/fluidsynth/`，用 ctypes 載入 |

沒有 FluidSynth 一樣可以編譜，只是聽不到鋼琴音、也不能匯出鋼琴音軌。

## 五分鐘上手

1. **檔案 → 匯入 MIDI**，選一個鋼琴 MIDI。
   - 兩軌的 MIDI 會直接把兩軌當成左右手（這是最常見的情況，也最準）。
   - 軌數不是兩軌時，會照各軌的平均音高分手。
2. 程式會問**要不要自動排譜**。答應的話，音高會被排到 28 條鍵道上。
   - 不排譜也可以，但那樣只有**音高模式**看得到東西（其他模式的鍵道位置是假的）。
3. 按 <kbd>1</kbd> 切換檢視模式，找到你習慣的看法。
4. 按 <kbd>Space</kbd> 試聽。
5. 用 <kbd>2</kbd> 開放置模式加音符，或直接拖拉既有音符調整。
6. **檔案 → 另存新檔**存成 XML 或 JSON。

## 三種檢視模式

按 <kbd>1</kbd> 循環切換，或用「檢視」分頁的按鈕。

| 模式 | 縱軸 | 適合 |
|---|---|---|
| **小節** | 每小節等高 | 對齊小節、看譜面結構 |
| **時間均分** | 每毫秒等高 | 看實際節奏密度、對音訊 |
| **音高** | 每毫秒等高，橫軸是 88 鍵 | 改音高、力度、踏板 |

**音高模式**是鋼琴捲軸：橫軸直接對應鋼琴鍵，底部有一排真的琴鍵，音符落到判定線時會亮起來。
左側是**延音踏板欄**，左右兩側邊緣是**力度曲線欄**（左手在左、右手在右）。

判定線永遠固定在**鍵盤上緣**——音符碰到鍵盤頂端就是判定的那一刻。

## 編輯操作

### 選取

- 左鍵點音符＝選取，拖曳＝框選
- <kbd>Ctrl</kbd>+點擊＝加選 / 取消
- <kbd>Ctrl</kbd>+<kbd>A</kbd> 全選、<kbd>Esc</kbd> 取消選取

### 放置音符

按 <kbd>2</kbd>（或工具列「放置音符」）進入放置模式，游標會變成十字。
點一下放一顆；**按住往上拖**可以直接拉出長度，tap 被拉長會自動變成長押。

放置參數在同一排：時值、左右手、寬度、類型。

### 改長押的長度

游標移到長押的**尾端**（方塊上緣）會變成上下箭頭，按住拖曳就能改長度。
**放置模式和一般模式都能用**。長度會吸附在目前選的時值的整數倍上，狀態列顯示實際毫秒數。

### 移動

| 操作 | 效果 |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> | 時間前後移動 1/32 音符 |
| <kbd>←</kbd> <kbd>→</kbd> | 鍵道左右移動（音高模式是改音高） |
| <kbd>Shift</kbd>+方向鍵 | 一次移動 10 格 |

右鍵選單的「時間與時值 → 整組平移」可以照拍數、自訂拍數或固定毫秒批次移動。

### 音符屬性

右鍵 → 音符屬性：

- **類型**：Tap / Soft / Long / Staccato / Slide / Trill
- **左右手**：<kbd>R</kbd> 右手、<kbd>L</kbd> 左手
- **寬度**：1～6 格
- **遊戲譜面隱藏**：音會響但畫面上不顯示（存成寄主的 `sub_note`）

> MIDI 模式下改左右手會**連 MIDI 音軌一起搬**，否則自動排譜會照音軌把手改回去。

### 音階輔助

工具列「音階輔助」打開後，在譜面上按住往上拖，就會照偵測到的調性放下一整組音。
18 種音型：音階、三度、三/七和弦琶音，以及半音階、全音階、五聲、藍調、各教會調式、減音階。

對稱音階（半音階、全音階、減音階）會以**你下筆的那個音**為起點，其餘照譜面主音。

### 手別篩選與幽靈音符

「編輯」分頁可以選只編右手或只編左手。被濾掉的那一手會變成**半透明的參考影子**——
看得到、點不到、框選和全選也不會選到。可以在偏好設定關掉影子。

## 播放

<kbd>Space</kbd> 播放/暫停。播放時畫面會跟著捲動，判定線固定在鍵盤上緣。

- **音源**：載入的音訊檔（wav/mp3），以及可選的第二音源
- **打擊聲**：音符過判定線時播 Tap 音效，可在「播放」分頁開關
- **沒有音樂檔也能播**：右鍵 →「播放 MIDI」用內建鋼琴音源直接聽譜面
- **播放偏移**：判定線和聲音對不上時，用「播放」分頁的偏移設定校正

播放中可以編輯，也可以拉音量——音量會即時套用，不會中斷播放。

## 工具選單

### 節奏與音高

| 工具 | 做什麼 |
|---|---|
| **量化** | 把音符起點對齊到拍點格線。可調**量化強度**（0～100%）、格點大小、只處理選取或整譜、要不要連長度一起 |
| **把音符吸到調內** | 把離調的音吸到最近的調內音。偵測不確定時會先問你 |
| **修補缺漏的拍點** | `beat_data` 漏拍時 BPM 會算成一半。這個會找出「間距是別人整數倍」的缺口補回去 |

### 音符整理

- **處理長條尾端**：長押尾巴和同手下一顆的最小間隔。可選「沒重疊就留間隔」（分解和弦不動）、「長押期間最多讓幾顆音進來」、或「一律裁到下一顆」
- **處理左右重疊**：同時起音的音符鍵道重疊時讓開
- **長押長度修整**：把 MIDI 的延音長度改成接近真正按鍵的長度
- **移除重複音符**：同 start 同 pitch 的重複

### 其他

- **樂曲總資訊**：BPM、總拍號、整體位移
- **以 MIDI 重建修復**：拿原始 MIDI 對齊時間、校正拍點、還原力度與踏板
- **延音踏板**：依和聲自動產生踏板，或清除
- **從別的譜面複製**：把另一份譜的力度／踏板套過來

## 偏好設定

**設定 → 偏好設定**，分成五個分頁：

| 分頁 | 內容 |
|---|---|
| **一般** | 語言（繁中／簡中／English） |
| **顯示** | 力度數字、強弱曲線、調性高亮、幽靈音符、狀態列、音高編號、鍵盤高度、深色模式、踏板欄、力度明暗 |
| **編輯** | 鎖調、滾輪方向、轉譜風格、匯出音訊處理 |
| **效能** | 復原歷史上限（MB）、音效輸出延遲補償 |
| **快捷鍵** | 見下 |

**復原歷史上限**：一筆歷史大約是「音符數 × 0.5KB」。譜面越大能留的步數越少（至少 8 步）。
記憶體小的機器可以調小；大譜面編輯時如果覺得吃太多記憶體，先動這裡。

## 匯出

| 項目 | 說明 |
|---|---|
| **另存新檔** | XML（官方格式）或 JSON |
| **匯出 MIDI** | 左右手分成兩軌，保留力度 |
| **匯出完整曲目** | 譜面＋音訊打包成遊戲的資料夾結構。會問要不要順便算一份 MIDI 鋼琴音軌 |

匯出鋼琴音軌走的是播放那條路（力度、trill/staccato 表情、CC64 延音踏板都在），
所以匯出的東西和你在編輯器裡聽到的一致。

## 開發

### 跑測試

```bash
python -m unittest discover -s . -p "test_*.py"
```

目前 40 個測試檔、697 個測試，全部通過。測試不需要顯示器，
但 Windows 以外的環境要設 `QT_QPA_PLATFORM=offscreen`。

### 打包

```bash
python -m PyInstaller NostalgiaChartEditor.spec --noconfirm --clean
```

產出在 `dist/NostalgiaChartEditor.exe`（單檔，約 190MB，含 FluidSynth 與音源）。

> 點火測試時注意：`Start-Process` 回傳的 PID 是 PyInstaller 的**啟動器**，
> 會停在 ~9MB 且沒有視窗標題。真正的程式是同名的**子行程**（~80MB）。
> 用 `Get-Process NostalgiaChartEditor` 列出全部再看，並給它 40～60 秒解壓縮。
